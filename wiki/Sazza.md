## 参与

### 第一幕

当队伍首次通过[翡翠林地](Emerald_Grove.md "翡翠林地")入口接近[临时监狱](Makeshift_Prison.md "临时监狱")时，他们发现萨扎被[阿尔卡](Arka.md "阿尔卡")用弩指着，阿尔卡想为她死去的兄弟[卡农](Kanon.md "卡农")报仇。阿尔卡的朋友[门诺斯](Memnos.md "门诺斯")试图劝阻她不要复仇。队伍成员可以选择通过说服她或挡在阿尔卡的弩前来帮助萨扎；他们也可以让萨扎死在阿尔卡手中。如果在阿尔卡和门诺斯离开后萨扎受到攻击，她可以呼叫守卫，守卫会像对待任何其他被攻击的中立角色一样反应。

如果队伍帮助萨扎然后与她交谈，她会向他们介绍一位强大的治疗者，[真魂者女祭司迦特](Gut.md "迦特")。萨扎随后作为[临时同伴](Companions.md#Temporary_Companions "同伴")加入，必须护送出林地。如果队伍表示他们的意图是[拯救地精萨扎](Save_the_Goblin_Sazza.md "拯救地精萨扎"),她承诺会在她的部落中为他们说好话，帮助绕过[地精营地](Goblin_Camp.md "地精营地")和[破碎圣所](Shattered_Sanctum.md "破碎圣所")的检查站。然而，当他们遇到[明萨拉](Minthara.md "明萨拉")时，她试图将队伍呈现为俘虏以掩盖她在突袭中的失败，并被指出队伍由[真魂者](True_Soul.md "真魂者")组成。随着惩罚的威胁迫在眉睫，队伍可以决定她是被杀死还是被监禁。

- 如果在萨扎被第二次饶恕后与她交谈，通过DC 10的[游说](Persuasion.md "游说")[检定](Ability_Check.md "检定")说服她分享位于X: -133 Y: 398的秘密藏匿处位置。
- 如果萨扎没有被释放并护送出林地，[拯救地精萨扎](Save_the_Goblin_Sazza.md "拯救地精萨扎")任务将以她的死亡结束。
- 如果在萨扎被释放并护送出林地后所有三个地精领袖被杀死，她会在第三个地精领袖死亡时立即死亡。
- 如果萨扎被释放，[明萨拉](Minthara.md "明萨拉")没有被杀死但失去意识，其他两个地精领袖被杀死，她会保持存活并在第二幕中遇到。
- 如果在迦特死亡、明萨拉被击晕后萨扎被释放，她会站在明萨拉的房间里，她的任务在[长休](Long_Rest.md "长休")之前不会继续，之后明萨拉的尸体消失。过场动画仍然播放，队伍可以选择饶恕萨扎。

### 第二幕

如果萨扎在[第一幕](Act_One.md "第一幕")中幸存下来，她可以在[月出之塔](Moonrise_Towers.md "月出之塔")的观众厅再次见到，与其他几个地精一起等待审判，因为他们未能获得神器。队伍可以决定她是被释放还是被处决（以不同程度的残忍）。如果萨扎在月出之塔被释放，会获得一个成就。

#### 释放地精

- [邪念] _把你们的痛苦放在一边。释放他们。_ -1 -1 +1 -1 -1
- 守卫。释放他们。 -1 -1 +1 -1 -1

#### 处决他们自己

- [邪念] 把自己劈开。_咔嚓-咔嚓！_干活的时候要微笑！ +1 -1 -1
- [邪念] 我梦想着血池深到可以在里面洗澡。给我放一浴缸。 +1 -1 -1
- 把你们的内脏洒在地上。我想看你们流血。 +1 -1 -1
- [邪念] 求饶！窒息！死亡！ +1 -1 -1
- 一个字也别说了。事实上——你们任何人都别再呼吸了。 +1 -1 -1

#### 战斗审判

- 我会给你一个公平的机会。与我战斗——你要么死，要么杀死我，你就可以自由离开。 -1 +1 +1
- [弃誓者] 这将是战斗审判。成为你自己命运的主人。 -1 +1 +1
- [圣武士] 这将是战斗审判。如果你想活下去，你必须为自己而战。 -1 +1 +1
- [狂战士] 我们将在**鲜血**中决定。你打得好，你就活。 -1 +1 +1
- [野蛮人] 动物只有在被逼到角落时才会展示真正的力量。向我展示你的。_战斗。_ -1 +1 +1
- [邪念] 我会亲手做这件事，总是感觉更好。 -1 +1 +1

如果萨扎在月出之塔被释放，萨扎和其他地精逃离该地区，再也没有消息。队伍随后在对话选项中指出，他们可能在没有[月光灯笼](Moonlantern.md "月光灯笼")的情况下死于[幽影诅咒](Shadow_Curse_(Condition).md "幽影诅咒（状态）")。

### 尾声

然而，如果萨扎被饶恕，在[尾声](Epilogue.md "尾声")中的[感恩之言箱](Chest_of_Grateful_Words.md "感恩之言箱")中可以找到她的[一封残信](Parchment_from_Sazza.md "一封残信")。信中说她一直在游荡，寻找仍然忠于至上真神的人（不知道她的"女神"已经陨落），最终被关进笼子，被_脾气暴躁的猫人_（可能是[塔巴西](https://forgottenrealms.fandom.com/wiki/Tabaxi)）俘虏。在她的信中，萨扎请求玩家角色再次拯救她。

## 同伴赞同

### 第一幕

- 在[翡翠林地](Emerald_Grove.md "翡翠林地")监狱处理被俘的萨扎：
- 允许阿尔卡射杀萨扎：+1+1
  - 站在阿尔卡的弩和萨扎之间：+1
  - 阻止阿尔卡射杀萨扎（成功的威吓或游说检定）：+1-1+1-1+1
- 在让阿尔卡离开她之后杀死萨扎不会导致任何同伴赞同变化。
- 当萨扎在笼子里时与她交谈：_"成交。我会把你弄出来。"_ +1 -1 -1
- 在盖尔在场的情况下化解局势会导致他向玩家角色提供一次对话，在对话中他向他们讲述了[深水城](Waterdeep.md "深水城")的类似情况。
- 在将萨扎从笼子里释放后与她交谈：
- 选择 _"成交，签字盖章"_ 或 _"跟着我。我会保护你"_：-1 -1 -1
- 在地精营地：
  - 在明萨拉面前为萨扎辩护：-1 +1 +1 -1 -1
  - 指责萨扎对明萨拉撒谎：+1 -1 +1 +1 +1
